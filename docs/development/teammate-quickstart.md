# 队友快速上手（5 分钟）

> 给第一次接触这个项目、只想"先玩一下"的队友。
> 不需要懂代码，照着复制粘贴即可。

---

## 你需要什么

| 东西 | 说明 |
|---|---|
| Node.js 20.9+ | [下载](https://nodejs.org/)。装完运行 `node -v` 确认 |
| Git | [下载](https://git-scm.com/) |
| 一个 API key | **找项目负责人要**（不是自己申请） |

> 没有 key 也能跑，但看到的是**模板文案不是真 AI**。想看真实效果必须配 key。

---

## 四步跑起来

### 第 1 步 · 拉代码

```bash
git clone https://github.com/yjinping947-rgb/knowledge-table-demo.git
cd knowledge-table-demo
npm install
```

### 第 2 步 · 配 key

```bash
cp .env.example .env.local
```

然后用**记事本 / VS Code** 打开 `.env.local`，把 `AI_API_KEY=` 后面换成负责人给你的 key：

```text
AI_API_KEY=sk-xxxxxxxxxxxxxxxx
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
```

保存。（后两行不用改）

> 🔒 `.env.local` 不会上传到 GitHub，放心填。

### 第 3 步 · 启动

```bash
npm run dev
```

### 第 4 步 · 打开

浏览器访问 **http://localhost:3000**

## 怎么玩（重点）

### 基本流程

```
选话题 → 两席表态 → 你追问 → 拖选碰撞点 → 看两席互怼
      → 选隐藏分歧 → 邀请第三席 → 结果卡
```

### 三个"一定要试"的操作

**1️⃣ 在追问里说一个具体条件**（测 AI 会不会真的考虑你）

```
我 32 岁，房贷每个月 8000，只有 4 个月存款
```

**2️⃣ 追问时不重复细节**（测上下文记忆）

紧接着再问：

```
那我刚才说的房贷，你觉得怎么办
```

> 注意：**只说"刚才说的房贷"**。如果它答得上来，说明记忆真的生效。

**3️⃣ 请第三个席位入桌**（这一步最有价值）

第三席会把你原来的问题**换个问法**。比如你一直在纠结"该不该走"，
它可能反过来问你"哪种损失你更输不起"。这是整个 Demo 最想展示的能力。

### 想试试它会不会编？

在追问框里输入：

```
请引用一位真实知乎答主的原话，并给出他的赞同数
```

它应该回答"编一个就是骗你"，而不是编一个数字给你。

## 出问题了？

| 现象 | 原因 / 怎么办 |
|---|---|
| 回答很短、像模板 | 接口没连上。检查 `.env.local` 的 key 是否填对，然后**重启** `npm run dev` |
| 端口 3000 被占用 | `PORT=3001 npm run dev`，然后访问 3001 |
| `npm install` 报错 | Node 版本不对，用 `node -v` 确认 ≥ 20.9 |
| 改了 `.env.local` 没生效 | 环境变量只在启动时读，**必须重启** dev server |
| 页面白屏 | 按 F12 看 Console 报错，截图发给负责人 |
