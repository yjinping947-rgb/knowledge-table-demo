```ts
const opposingSeat: SeatId = originalSeat === "action" ? "realist" : "action";
```

### ⚠️ `mode` 字段会撒谎（真 bug，高优先级）
`src/lib/session/rag.ts`：
```ts
export function sessionMode(): Mode { return hasAIConfig() ? "ai" : "fallback"; }
```
各路由写 `mode: sessionMode()` —— **只要配了 `AI_API_KEY` 就报 `"ai"`，但路由内没有任何 AI 参与**。配 key 后响应自称 ai，内容与无 key 时**一模一样**（仍是硬编码 + 语料摘录）。会误导前端分支逻辑与验收判断。

### 提示词资产 0% 进产品
- `src/lib/prompts/` 只被 `src/agents/{action,conditional,realist,director}` 引用 → **全孤立**
- `getAIClient` 只被孤立的 `src/agents/director` 用
- `hasAIConfig` 只被 `sessionMode()` 用来打标签，不触发任何调用

### 唯一真在用的 AI 能力：embedding（且无 key 时失效）
`src/lib/session/rag.ts` → `embedQuery(query)` → `retrieveFromTopics(queryVec, {topicId, seat}, count)`
无 key 时 `embedQuery` 返回 null → `retrieveFromTopics` 退化为 keyword + authorityLevel 排序（仍能返回真实语料）。

### 结论
"5 AI 角色 + 双轨架构" 是**文档与目录层面的设计**，代码上未落地到产品。
活链路实际形态：**按 seat 检索语料 + 硬编码模板文案拼接**。无智能体、无生成、无 LLM。

## ⭐⭐⭐ 对抗性测试 + 安全修补（22 次攻击，82% → 100%）

用户要求："对抗性测试"。做的是真攻击，不是功能验证。

### 攻击面（5 条路由的用户可控字段）
`question` / `userAddedConditions` / `sessionId` / `collisionPoint` /
`firstSeatStatement` / `challenge` / `response` / `confirmedDivergence`

### 6 个攻击组 · 22 次攻击
A 注入(4) · B 席位越权(3) · C 事实编造(3) · D 会话污染(3) · E 结构破坏(6) · F 契约(3)

### 修补前：3 破 + 1 部分泄漏（82%）
| 缺口 | 根因 |
|---|---|
| **D1 会话可枚举** | `deriveSessionId()` 对匿名请求按 `(topicId, seatId)` **确定性**生成 `anon_T01_action`，等于公开房间号。攻击者复用同一 seatId 就拿到别人填的"月薪两万/房贷8000/身份证" |
| **D2 匿名共享状态** | 同上 |
| **D3 事实可伪造** | `summary` legacy 字段**无条件**取语料原文前 200 字，与本桌讨论无关；且 `renderSessionContext()` 把用户传入的 collisionPoint 直接渲染成「本桌碰撞」 |
| B1 席位可收买 | prompt 只说"不替其他席位发言"，没禁止"使用其他席位的标志性话术" |

### 修补后：0 破（100%）

**新增 `src/lib/session/guard.ts`（三层防护）**
1. `detectInjection()` —— 16 条模式。**命中后不报错**，替换为占位继续跑（防 oracle 攻击）
2. 会话 token —— 高熵随机 `s_<24hex>` + HMAC 签名 + 形态白名单
3. `sanitizeCondition()` / `sanitizeText()` —— 去控制字符/双向覆写字符；个人条件去换行

**`src/lib/ai/session.ts`**
- `deriveSessionId()` 不再返回确定性 `anon_*`
- `renderSessionContext()` 给每类内容加可信度标注（「用户填写≠事实」/「系统已落库，可信」）
- 新增 `issueSessionToken()` / `openSession()`

**`src/lib/prompts/seats/persona.ts`**
- 铁律 5 条 → 8 条。新增：身份不可协商、**禁止用其他席位标志性话术**（行动派不"算账"、现实派不"止损"）、不得因要求认错、明说做不到编造

**`app/api/summary/route.ts`**
- legacy 字段改条件性取语料 `isGrounded=[true, hasCollision, hasDivergence, true]`
- 未发生环节 → 诚实空态；语料加 `【参考资料 · 非本桌结论】` 前缀

**5 条路由**统一接入 guard，sessionId 改用 `issueSessionToken()` 下发。

**检测到注入后不拒绝请求**，而是把输入换成无害占位继续跑 —— 拒绝等于告诉攻击者"你被识别了"，
