## 版本 2：队友不在同一网络（需要内网穿透）

如果队友不在同一个 WiFi 下，上面的地址他打不开。用这条命令把本地服务
暴露成公网地址：

```bash
npx cloudflared tunnel --url http://localhost:3000
```

（或 `npx ngrok http 3000`，需要 ngrok 账号）

命令会输出一个 `https://xxx.trycloudflare.com` 之类的公网地址，
把这个地址发群里即可。

**注意**：这个地址任何人拿到都能用，且消耗你的 key 额度。
演示完按 `Ctrl+C` 关掉就失效。

## 版本 3：队友想自己跑（各自用自己的 key）

```bash
git clone https://github.com/yjinping947-rgb/knowledge-table-demo.git
cd knowledge-table-demo
npm install
cp .env.example .env.local
# 用编辑器打开 .env.local，填【你自己的】key
npm run dev
```

然后访问 http://localhost:3000

详见 `docs/development/teammate-quickstart.md`。

# 三种方式的取舍

| | 队友要做什么 | key 用谁的 | 你能关机吗 |
|---|---|---|---|
| **局域网直连** | 打开网址 | 你的 | ❌ 不能 |
| **内网穿透** | 打开网址 | 你的 | ❌ 不能 |
| **队友自己跑** | clone + 填自己 key | 各自的 | ✅ 能 |

## 重要限制

**局域网 / 内网穿透方式下，你的电脑必须一直开着**，队友才能访问。
因为你电脑就是服务器。

如果要"你关机了队友还能玩"，只有两条路：
1. 部署到云服务器（key 放云端环境变量）
2. 让队友自己跑

## 安全提醒

- 局域网方式下，**同一网络的人都能访问**。如果你在咖啡厅/共享办公，
  注意别让陌生人拿到你填的隐私信息。
- 内网穿透的地址**任何人拿到都能用**，演示完记得关掉。
- 这两种方式都在**消耗你的 key 额度**。
