# 推送操作清单（照做即可）

> 场景：把"接通 LLM + 对抗防护 + 文档修正"这批改动推到 GitHub，
> 让队友能拉到最新代码。
>
> **关键前提：key 不在代码里，永远不会被 push。**

---

## 为什么必须开分支（不能直接推 main）

仓库 `.harness/rules/branch-policy.md` 明确写着：

> 不允许直接在 `main` 上 commit（用 PR）

仓库还配了 CODEOWNERS（5 角色 reviewer 路由），走 PR 才会自动请求对应 reviewer。

---

## 操作步骤

### 第 1 步：建分支

命名遵循 `<type>/<scope>-<short-desc>`：

```bash
git checkout -b feat/agents-llm-integration-and-guard
```

### 第 2 步：确认 key 不会被提交

```bash
# 应该输出 .gitignore:5 之类的行，说明被忽略
git check-ignore -v .env.local

# 应该搜不到任何真实 key
git grep -n "sk-[a-zA-Z0-9]\{20,\}"
```

两条都符合预期再往下走。

### 第 3 步：提交

```bash
git add .
git commit -m "feat(agents): 接通 DeepSeek 并补齐对抗性防护"
```

pre-commit 钩子会自动跑 `npm run lint` 和 `npm run test`。
（本次已本地验证：lint 零警告、tsc 零错误、test:all 全绿）

### 第 4 步：配置 GitHub 认证（只需做一次）

仓库当前**没有认证**，直接 push 会被拒。

**推荐用 Personal Access Token：**

1. 打开 https://github.com/settings/tokens
2. `Generate new token` → `Generate new token (classic)`
3. Note 随便填（如 `knowledge-table-push`），Expiration 选 30 天
4. **勾选 `repo`** 权限（这一个就够）
5. 生成后**立刻复制**（离开页面就看不到了）

**配置凭据缓存：**

```bash
git config --global credential.helper manager
```

然后 push 时会弹窗 —— 用户名填 GitHub 用户名，密码栏**粘贴 token**（不是你的登录密码）。

### 第 5 步：推送

```bash
git push -u origin feat/agents-llm-integration-and-guard
```

### 第 6 步：开 PR

推送成功后终端会打印一个链接，点它就能开 PR。
或者直接访问：

```
https://github.com/yjinping947-rgb/knowledge-table-demo/compare
```

PR 描述建议写清：

- **变更前预期**：页面回答是语料摘录，答非所问
- **变更后端测效果**：5 条路由全部返回 `mode=generated`，追问能记住上下文
- **影响范围**：`src/lib/ai|prompts|session` + `app/api/*`，前端零改动

> 仓库有 PR 模板（`.github/PULL_REQUEST_TEMPLATE.md`），会要求填这两栏。

## 队友怎么拉

```bash
git fetch origin
git checkout feat/agents-llm-integration-and-guard
npm install
cp .env.example .env.local
# 在 .env.local 里填【自己的】key
npm run dev
```

**每个队友填自己机器上的 `.env.local`，互不影响，也不会上传。**

---

## 合并后队友怎么同步

一旦 PR 合进 `main`：

```bash
git checkout main
git pull
npm install
npm run dev
```

## 常见问题

| 报错 | 原因 / 解决 |
|---|---|
| `Authentication failed` | token 没配好，或漏勾 `repo` 权限 |
| `Invalid username or token` | 密码栏填的是 GitHub 登录密码，要填 **token** |
| pre-commit 被拦 | 钩子跑测试失败，先看输出；`git commit --no-verify` 可绕过但**不推荐** |
| `Your branch is behind` | 先 `git pull --rebase origin main` |
| 推上去发现多推了文件 | `git reset HEAD~1` 撤销 commit 后重新 add |
